# Campus Services Portal - Frontend Technical Documentation

## Executive Overview
The **Campus Services Portal** frontend is an enterprise single-page application built on **Angular 19**. It features a 100% standalone component architecture, fine-grained Angular Signals reactivity, lazy-loaded routing modules, typed HTTP services, and strict adherence to university business requirements.

## Part 4: Forms Register

The frontend incorporates both **Reactive Forms** (for dynamic, multi-field, and mission-critical workflows) and **Template-driven Forms** (for standard authentication and simple settings).

| Form Identifier | Feature Area | Paradigm | Structure & Key Controls | Validation Rules & Error Handling |
| :--- | :--- | :--- | :--- | :--- |
| **Student Registration Form** | Authentication | Reactive | Full Name, Index Number, University Email, Password, Confirm Password, Faculty Selection | Regex Index check (`PS/YYYY/NNNN`), university email domain check, cross-field password match validator. Errors displayed on touch. |
| **User Sign-In Form** | Authentication | Template-driven | Email / Username, Password, Remember Me checkbox | Required field validation, standard email formatting. Submit disabled while in-flight. |
| **Profile & Contacts Editor** | Student Profile | Reactive | Contact Details, FormArray of Phone Numbers (Primary, Mobile), FormArray of Addresses | FormArray dynamic row addition/deletion; phone number regex; mobile OTP verification requirement. |
| **Hostel Application Form** | Hostel | Reactive | Hostel Selection, Room Category, Academic Term Start Date, Academic Term End Date, Reason | Cross-field date validator ensuring EndDate > StartDate; room capacity check. |
| **2D Workstation Builder Form** | Lab Management | Reactive | Nested FormArray: Root FormGroup -> rows (FormArray) -> columns (FormArray) -> Workstation metadata | Automatic coordinate indexing `(Row, Col)`; duplicate workstation identifier prevention. |
| **Lab Seat Reservation Form** | Lab Booking | Reactive | Lab Selection, Date Picker, Time Slot Dropdown, Workstation Selection | Custom future-date validator; slot availability check; 10-minute seat hold timer lock. |
| **Complaint Lodging Form** | Complaints | Reactive Dynamic | Category Dropdown, Title, Dynamic Description Fields, Urgency Level, Optional Image Upload | Dynamic control injection based on selected category; file size/type validation. |
| **Certificate Request Form** | Certificates | Reactive | Certificate Type Dropdown, Purpose Text, Delivery Mode, Copies Counter (1-5) | Number of copies minimum/maximum bounds (1-5); duplicate active request prevention. |
